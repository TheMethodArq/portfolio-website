### 4.2 Core Services

**AI Routing Engine (ai-routing-engine)**
- **Purpose:** Intelligent model selection based on task requirements
- **ASO Usage:**
  - Content analysis → Claude Sonnet 4.5 (reasoning, strategy)
  - Data processing → GPT-4o (structured output)
  - Vector embedding → text-embedding-3-large
  - Code generation → Claude Sonnet 4.5 (code capability)
- **Configuration:** Tenant-level cost/latency preferences

**Orchestration Service (ai-model-orchestration-service)**
- **Purpose:** Agentic workflow execution
- **ASO Usage:**
  - ASO Supervisor Agent (24/7 monitoring)
  - Weekly intelligence report generation
  - Automated task creation
  - Cross-model validation workflows
- **Framework:** LangGraph-based state machines

**Runtime Service (system-runtime)**
- **Purpose:** Safe code execution environment
- **ASO Usage:**
  - SEO audit script generation
  - Headless browser automation (Puppeteer)
  - Data extraction scripts
  - Schema validation
- **Security:** E2B sandboxed execution

**Analytics Data Layer (analytics-data-layer)**
- **Purpose:** Multi-tenant data storage and retrieval
- **ASO Usage:**
  - SERP snapshots (time-series)
  - Vector embeddings (content/queries)
  - Client metrics (VVS, rank, traffic)
  - Competitive benchmarks
- **Storage:** PostgreSQL (structured) + Qdrant (vectors)

### 4.3 Data Flow Architecture

**Typical VVS Calculation Flow:**

1. **Client Request** → Dashboard triggers VVS update for keyword "enterprise CRM"
2. **Routing** → ai-routing-engine selects:
   - SERP analysis: GPT-4o (structured extraction)
   - Embedding: text-embedding-3-large
   - Strategic interpretation: Claude Sonnet 4.5
3. **Execution:**
   - system-runtime launches Puppeteer script to capture SERP
   - Extracts top 10 results + client's ranking
   - Sends content to embedding model
   - Calculates centroid + semantic distance
4. **Storage** → analytics-data-layer stores:
   - Raw SERP HTML
   - Extracted vectors
   - VVS score (0-1 scale)
   - Timestamp
5. **Intelligence** → ai-model-orchestration-service:
   - Compares to historical VVS
   - Detects trends
   - Generates recommendations
6. **Delivery** → Dashboard displays VVS + explanation

#### F1: Five-Stage Transition Assessment

**Feature ID:** CORE-001  
**Priority:** P0 (Launch blocker)  
**Tier Availability:** All tiers

**Description:**
Algorithmic assessment of where a business exists in the Traditional → AI search transition.

**Stages Defined:**
1. **Stage 1: Traditional Presence** - Basic website, minimal SEO
2. **Stage 2: Search Visible** - Ranking for brand terms, some organic traffic
3. **Stage 3: AI-Ready** - Structured data, semantic optimization beginning
4. **Stage 4: Actively Optimizing** - Consistent content, vector alignment improving
5. **Stage 5: AI-Native Authority** - High VVS, LLM-referenced, training data present

**Calculation Methodology:**
```
Composite Score = 
  (Traditional Presence × 0.15) +
  (AI Readiness × 0.20) +
  (Vector Alignment × 0.30) +
  (Active Optimization × 0.15) +
  (AI Visibility × 0.20)
```

**Inputs Required:**
- Website URL
- Google Search Console access (optional, improves accuracy)
- Target keyword list (3-10 keywords)

**Output:**
- Stage number (1-5)
- Confidence score (0-100%)
- Stage-specific action plan
- Estimated time to next stage

**User Story:**
> "As a new user, I want to immediately understand where I stand in the AI search landscape so I know if I'm ahead or behind my competition."

**Acceptance Criteria:**
- [ ] Assessment completes within 60 seconds
- [ ] Confidence score >70% for clients with GSC connected
- [ ] Stage explanation uses non-technical language
- [ ] Action plan is specific to detected stage
- [ ] Historical stage progression tracked monthly

**Technical Notes:**
- Calls SYNAPTICA ai-ml-engine/domain/aso/transition_scorer.py
- Caches assessment for 30 days unless manually refreshed
- Requires minimum 3 months of data for Stage 4-5 assessment

#### F2: Vector Visibility Score (VVS™)

**Feature ID:** CORE-002  
**Priority:** P0 (Launch blocker)  
**Tier Availability:** Tier 2+

**Description:**
Proprietary metric measuring semantic distance from search intent. Predicts ranking potential and explains why content ranks or doesn't rank.

**Calculation Process:**

1. **SERP Embedding:**
   - Scrape top 10 results for target keyword
   - Extract main content (title, headers, body text)
   - Generate embeddings using text-embedding-3-large
   
2. **Intent Centroid:**
   - Calculate mathematical center of top 10 vectors
   - Weight by position (position 1 = 1.0x, position 10 = 0.3x)
   
3. **Distance Measurement:**
   - Calculate cosine distance from client content to centroid
   - Normalize to 0-100 scale (100 = perfect alignment)
   
4. **Trend Analysis:**
   - Compare to previous VVS measurements
   - Identify improving/declining scores
   - Correlate with actual rank changes

**VVS Scale:**
- **90-100:** Perfect Alignment (Top 3 potential)
- **75-89:** Strong Alignment (Top 10 likely)
- **60-74:** Moderate Alignment (Page 1 possible)
- **40-59:** Weak Alignment (Needs optimization)
- **0-39:** Poor Alignment (Wrong topic/angle)

**Output Includes:**
- VVS numerical score
- Plain-English explanation
- Missing semantic clusters (topics to add)
- Overrepresented clusters (topics to reduce)
- Recommended content changes
- Predicted rank if changes implemented

**User Story:**
> "As a marketing director, I want to know WHY my content isn't ranking so I can fix the right things instead of guessing."

**Acceptance Criteria:**
- [ ] VVS correlates with rank at r=0.75+ (validated against 1,000 keyword dataset)
- [ ] Calculation completes within 90 seconds
- [ ] Explanation includes minimum 3 specific recommendations
- [ ] Historical VVS chart shows 12-month trend
- [ ] VVS updates weekly automatically
- [ ] Can manually trigger VVS recalculation

**Technical Notes:**
- Embedding model: text-embedding-3-large (3,072 dimensions)
- Vector storage: Qdrant collection aso-vectors/{tenant_id}
- Cache SERP embeddings for 7 days (reduce API costs)
- Centroid calculation weights: Position 1 (1.0), Position 5 (0.6), Position 10 (0.3)

**Edge Cases:**
- If client not in top 100: Use "shadow VVS" (predict score without actual ranking)
- If SERP has <5 results: Flag as "Insufficient data"
- If query is branded: Skip VVS (not applicable to branded searches)

### 5.2 Tier 2+ Features

#### F4: Agentic Supervisor (ASO Manager Agent)

**Feature ID:** T2-001  
**Priority:** P1 (Post-launch enhancement)  
**Tier Availability:** Tier 2+

**Description:**
24/7 AI agent that monitors client performance, detects issues, and generates strategic recommendations automatically. Replaces human "success manager."

**Agent Capabilities:**

**Monitor Mode (Runs Weekly):**
- Ingest VVS scores for all tracked keywords
- Compare to 30/60/90-day baselines
- Detect anomalies (sudden drops, competitor gains)
- Cross-reference with Google algorithm updates (from SEO news APIs)

**Detect Mode (Triggered by anomalies):**
- Identify root cause (technical issue, content drift, competitor action)
- Assess severity (low/medium/high impact)
- Determine urgency (immediate/this week/this month)

**Plan Mode (Generates recommendations):**
- Create prioritized action list
- Estimate effort per task (hours)
- Predict impact per task (traffic gain)
- Generate PDF intelligence report

**Act Mode (Tier 3 only):**
- Execute approved optimizations via system-runtime
- Update meta descriptions
- Fix broken links
- Regenerate schema markup
- Submit updated sitemap

**User Story:**
> "As a time-strapped marketer, I want an AI expert watching my SEO 24/7 so I don't miss opportunities or threats."

**Acceptance Criteria:**
- [ ] Agent runs every Monday 6am client timezone
- [ ] Report generated within 10 minutes of run
- [ ] Report includes minimum 3 actionable recommendations
- [ ] Recommendations ranked by ROI (predicted impact / effort)
- [ ] Agent detects 90%+ of ranking drops within 7 days
- [ ] False positive rate <10%

**Technical Implementation:**
- Service: ai-model-orchestration-service
- Framework: LangGraph (state machine)
- Models:
  - Data analysis: GPT-4o (structured output)
  - Strategic reasoning: Claude Sonnet 4.5
  - Report writing: Claude Sonnet 4.5
- Trigger: scheduler-service (cron: 0 6 * * MON)

**Agent State Machine:**
```
START
  ↓
COLLECT_DATA (Fetch VVS, rank, traffic from analytics-data-layer)
  ↓
ANALYZE_TRENDS (Calculate deltas, identify anomalies)
  ↓
DETECT_ISSUES (Root cause analysis if anomalies found)
  ↓
GENERATE_PLAN (Create prioritized action list)
  ↓
WRITE_REPORT (PDF generation)
  ↓
NOTIFY_CLIENT (Email + dashboard notification)
  ↓
END
```

**Agent Output Example:**
```
ASO Intelligence Report - Week of Dec 30, 2025

EXECUTIVE SUMMARY
Your VVS improved +8 points this week (64 → 72), but Rank dropped -3 
positions due to a competitor publishing comprehensive guide content.

TOP 3 ACTIONS
1. [HIGH IMPACT] Add FAQ section to /pricing page
   - Effort: 2 hours
   - Predicted VVS gain: +6 points
   - Predicted rank gain: +2-3 positions
   
2. [MEDIUM IMPACT] Update meta description for "enterprise CRM" keyword
   - Effort: 15 minutes
   - Click-through rate optimization (not rank)
   
3. [DEFENSIVE] Monitor competitor "XYZ Corp" - published 5,000-word guide
   - Created content gap in "implementation timeline" topic
   - Recommendation: Publish case study addressing this gap
```

### Appendix C: VVS Calculation - Technical Deep Dive

**Step-by-Step Process:**

1. **SERP Capture**
   - Query: "enterprise CRM software"
   - Location: United States
   - Device: Desktop
   - Capture top 10 organic results

2. **Content Extraction**
   - For each result: Extract title, meta description, H1, H2, first 500 words
   - Clean HTML (remove navigation, ads, footers)
   - Concatenate into single text block per result

3. **Embedding Generation**
   - Model: text-embedding-3-large
   - Input: Cleaned text (max 8,000 tokens per result)
   - Output: 3,072-dimensional vector per result

4. **Centroid Calculation**
   - Weighted average of top 10 vectors
   - Weights: Position 1 (1.0), Position 2 (0.95), ..., Position 10 (0.3)
   - Formula: `centroid = Σ(weight_i × vector_i) / Σ(weight_i)`

5. **Client Distance**
   - Embed client's page content (same method)
   - Calculate cosine distance: `distance = 1 - cosine_similarity(client_vector, centroid)`

6. **Normalization**
   - Convert distance (0-2 range) to score (0-100 scale)
   - Formula: `VVS = 100 × (1 - distance/2)`
   - Clamp to 0-100 range

7. **Explanation Generation**
   - Identify semantic clusters (via K-means on centroid neighbors)
   - Compare client content to each cluster
   - Generate "missing topics" and "overrepresented topics" lists
   - Use Claude Sonnet 4.5 to write plain-English explanation

**Example Output:**
```
VVS Score: 68/100

Your content is moderately aligned with search intent. The top-ranking 
pages emphasize three key topics you're underrepresenting:

Missing Topics:
1. "Integration capabilities" (mentioned in 8/10 top results, 0 times in yours)
2. "Implementation timeline" (7/10 vs. 0)
3. "Pricing transparency" (6/10 vs. 0)

Overrepresented Topics:
1. "Company history" (You mention 5 times, top results average 0.3 times)

Recommendation: Add a dedicated section on integrations and expected 
implementation timelines. Reduce emphasis on company background.

Predicted Impact: +8 VVS points, ~3 rank positions
```
